# Regulamento (CEE) n.º 1484/86 da Comissão de 15 de Maio de 1986 relativo ao restabelecimento da cobrança de direitos aduaneiros aplicáveis a países terceiros quanto a certos produtos originários da Jugoslávia

**Já não está em vigor** (fim de validade registado no Cellar: 1986-12-31). Serve para saber que regra se aplicava antes; para a regra actual, procurar o acto que o substituiu.

**Texto:** versão original publicada no Jornal Oficial (sem as alterações posteriores).

## Preâmbulo

A COMISSÃO DAS COMUNIDADES EUROPEIAS,

Tendo em conta o Tratado que institui a Comunidade Económica Europeia,

Tendo em conta o Acordo de Cooperação entre a Comunidade Económica Europeia e a República Socialista Federativa da Jugoslávia (1), e, nomeadamente, o seu Protocolo nº 1,

Tendo em conta o Regulamento (CEE) nº 3138/85 do Conselho, de 22 de Outubro de 1985, relativo ao estabelecimento de tectos e de uma vigilância comunitária quanto às importações de certos produtos originários da Jugoslávia (2), em conformidade com o artigo 1º,

Considerando que o artigo 1º do protocolo supra prevê que a importação dos produtos indicados infra, com direitos aduaneiros reduzidos segundo o artigo 15º do Acordo de Cooperação está submetida ao tecto anual indicado em face, para lá do qual os direitos aduaneiros aplicáveis a países terceiros podem ser restabelecidos:

(em toneladas)

1.2.3 // // // // Nº da pauta aduaneira comum // Designação das mercadorias // Tecto // // // // 73.18 // Tubos (incluindo os esboços) de ferro macio ou de aço, com exclusão dos artefactos do nº 73.19: B. Outros // 10 212 // // //

Considerando que as importações na Comunidade desses produtos originários da Jugoslávia atingiram o tecto supramencionado; que o restabelecimento da cobrança de direitos aduaneiros aplicáveis a países terceiros para os produtos em questão é necessário em razão da situação do mercado comunitário,

ADOPTOU O PRESENTE REGULAMENTO:

## Texto

### Artigo 1.º

De 19 de Maio a 31 de Dezembro de 1986, a cobrança de direitos aduaneiros aplicáveis a países terceiros é restabelecida na importação na Comunidade dos seguintes produtos:

1.2.3 // // // // Nº da pauta aduaneira comum // Designação das mercadorias // Origem // // // // 73.18 // Tubos (incluindo os esboços) de ferro macio ou de aço, com exclusão dos artefactos do nº 73.19: B. Outros // Jugoslávia // // //

### Artigo 2.º

O presente regulamento entra em vigor no terceiro dia seguinte ao da sua publicação no Jornal Oficial das Comunidades Europeias.

O presente regulamento é obrigatório em todos os seus elementos e directamente aplicável em todos os Estados-membros.

Feito em Bruxelas, em 15 de Maio de 1986.

Pela Comissão
