# Regulamento (CEE) n.º 1844/86 da Comissão de 13 de Junho de 1986 que altera o Regulamento n.º 225/67/CEE, relativo às regras de determinação do preço para as sementes oleaginosas no mercado mundial

**Já não está em vigor** (fim de validade registado no Cellar: 1986-07-23). Serve para saber que regra se aplicava antes; para a regra actual, procurar o acto que o substituiu.

**Texto:** versão original publicada no Jornal Oficial (sem as alterações posteriores).

## Preâmbulo

A COMISSÃO DAS COMUNIDADES EUROPEIAS,

Tendo em conta o Tratado que institui a Comunidade Económica Europeia,

Tendo em conta o Regulamento nº 136/66/CEE do Conselho, de 22 de Setembro de 1966, que estabelece uma organização comum de mercado no sector das matérias gordas (1), com a última redacção que lhe foi dada pelo Regulamento (CEE) nº 1454/86 (2),

Tendo em conta o Regulamento nº 115/67/CEE do Conselho, de 6 de Junho de 1967, que fixa os critérios para a determinação do preço do mercado mundial das sementes oleaginosas bem como, o local de passagem na fronteira (3) com a última redacção que lhe foi dada pelo Regulamento (CEE) nº 1983/82 (4), e, nomeadamente, o seu artigo 7º,

Considerando que o artigo 3º do Regulamento nº 225/ /67/CEE da Comissão (5), com a última redacção que lhe foi dada pelo Regulamento (CEE) nº 1974/85 (6), prevê que, no caso de as ofertas e as cotações respeitarem a uma qualidade que não seja a qualidade-tipo para a qual foi fixado o preço indicativo, o seu montante é ajustado em conformidade com os coeficientes de equivalência incluídos no anexo;

Considerando que, pelo Regulamento (CEE) nº 1457/ /86 (7), o Conselho fixou, para a campanha de comercialização de 1986/1987 o preço indicativo para as sementes de girassol com um teor em óleo de 44 %; que convém ajustar, para a mesma campanha, os coeficientes de equivalência em causa que constam do anexo do Regulamento nº 225/67/CEE e que foram fixados para as sementes de girassol com um teor em óleo de 42 %;

Considerando que as medidas previstas no presente regulamento estão em conformidade com o parecer do Comité de Gestão das Matérias Gordas,

ADOPTOU O PRESENTE REGULAMENTO:

## Texto

### Artigo 1.º

O quadro do anexo do Regulamento nº 225/67/CEE é substituído pelo quadro seguinte:

« (em ECUs/100 kg)

1.2,3 // // // // Coeficiente de equivalência // 1.2.3 // // Montante a deduzir do preço // Montante a acrescentar ao preço // // // // A. Semente de colza e de nabita em proveniência: // // // - do Canadá // 1,268 // - // - dos outros países terceiros // 1,075 // - // B. Sementes de girassol em proveniência: // // // - dos Estados Unidos da América ou Canadá // - // 0,854 (1) resp. 1,854 (2) // - dos outros países terceiros // - // 0,592 (1) resp. 1,592 (2) // // //

(1) A aplicar aos preços válidos para um carregamento a realizar antes de 1 de Agosto de 1986.

(2) A aplicar aos preços válidos para um carregamento a realizar a partir de 1 de Agosto de 1986. »

### Artigo 2.º

O presente regulamento entra em vigor na data da sua publicação no Jornal Oficial das Comunidades Europeias.

O presente regulamento produz efeitos a partir de 1 de Abril de 1986.

O presente regulamento é obrigatório em todos os seus elementos e directamente aplicável em todos os Estados-membros.

Feito em Bruxelas, em 13 de Junho de 1986.
