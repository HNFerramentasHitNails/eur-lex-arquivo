# REGULAMENTO (CEE) Nº 3832/89 DA COMISSÃO de 20 de Dezembro de 1989 que altera o Regulamento (CEE) nº 1523/89, que determina as consequências da superação do limiar de intervenção para os limões, para a campanha de 1988/1989 em Espanha, para a fixação dos preços de base e de compra deste produto para a campanha de 1989/1990 —

**Já não está em vigor** (fim de validade registado no Cellar: 1990-05-31). Serve para saber que regra se aplicava antes; para a regra actual, procurar o acto que o substituiu.

**Texto:** versão original publicada no Jornal Oficial (sem as alterações posteriores).

## Preâmbulo

A COMISSÃO DAS COMUNIDADES EUROPEIAS,

Tendo em conta o Tratado que institui a Comunidade Económica Europeia,

Tendo em conta o Acto de Adesão de Espanha e de Portugal,

Tendo em conta o Regulamento (CEE) nº 1035/72 do Conselho, de 18 de Maio de 1972, que estabelece a organização comum de mercado no sector das frutas e produtos hortícolas (1), com a última redacção que lhe foi dada pelo Regulamento (CEE) nº 1119/89 (2), e, nomeadamente, o nº 4 do seu artigo 16º b,

Considerando que o Regulamento (CEE) nº 2285/88 do Conselho (3), com a última redacção que lhe foi dada pelo Regulamento (CEE) nº 1521/89 (4), fixou, para a campanha de 1988/1989, para os limões, um limiar de intervenção em Espanha e as consequências a tirar de uma superação;

Considerando que a Comissão verificou uma superação do limiar de intervenção fixado para os limões em Espanha para a campanha de 1988/1989 e que pelo Regulamento (CEE) nº 1523/89 da Comissão (5) determinou as consequências desta superação para os preços institucionais aplicáveis em Espanha para os limões, para o período compreendido entre 1 de Junho e 31 Dezembro de 1989;

Considerando que, pelo Regulamento (CEE) nº 3514/89 do Conselho (6), o Conselho fixou os preços de base e de compra dos limões aplicáveis em Espanha a partir de 1 de Janeiro de 1990 até ao final da campanha de 1989/1990; que, devido à superação do limiar de intervenção supracitado, é conveniente diminuir estes preços de 6 % e, em consequência, alterar o Regulamento (CEE) nº 1523/89;

Considerando que as medidas previstas no presente regulamento estão em conformidade com o parecer do Comité de Gestão das Frutas e Produtos Hortícolas,

ADOPTOU O PRESENTE REGULAMENTO:

## Texto

### Artigo 1.º

O artigo 2º do Regulamento (CEE) nº 1523/89 é alterado do seguinte modo:

1. O texto existente passa a constituir o nº 1.

2. É aditado o seguinte nº 2:

« 2. Os preços de base e os preços de compra dos limões aplicáveis em Espanha a partir de 1 de Janeiro de 1990 até ao final da campanha de 1989/1990, fixados pelo Regulamento (CEE) nº 3514/89 do Conselho (*), são diminuídos de 6 % e estabelecem-se do seguinte modo:

(Em ecus/100 kg líquidos)

1.2.3 // // // // Período // Preço de base // Preço de compra // // // // Janeiro // 20,22 // 11,86 // Fevereiro // 19,51 // 11,50 // Março // 20,30 // 11,86 // Abril // 21,23 // 12,43 // Maio // 21,73 // 12,72 // // //

Estes preços referem-se aos limões da categoria de qualidade I, calibre de 53 a 62 mm, apresentados em embalagem. Os preços incluem o custo da embalagem em que o produto é apresentado.

(*) JO nº L 344 de 25. 11. 1989, p. 1. ».

### Artigo 2.º

O presente regulamento entra em vigor na data da sua publicação no Jornal Oficial das Comunidades Europeias.

O presente regulamento é obrigatório em todos os seus elementos e directamente aplicável em todos os Estados-membros.

Feito em Bruxelas, em 20 de Dezembro de 1989.
