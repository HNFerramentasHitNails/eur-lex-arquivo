# Regulamento (CEE) n.º 2276/88 da Comissão de 25 de Julho de 1988 que altera o Regulamento (CEE) n.º 4122/87 relativo aos contingentes de importação no quadro das restrições quantitativas (campanha de pesca de 1988)

**Já não está em vigor** (fim de validade registado no Cellar: 1988-12-31). Serve para saber que regra se aplicava antes; para a regra actual, procurar o acto que o substituiu.

**Texto:** versão original publicada no Jornal Oficial (sem as alterações posteriores).

## Preâmbulo

A COMISSÃO DAS COMUNIDADES EUROPEIAS,

Tendo em conta o Tratado que institui a Comunidade Económica Europeia,

Tendo em conta o Regulamento (CEE) nº 360/86 do Conselho, de 17 de Fevereiro de 1986, que estabelece, para Espanha e Portugal, disposições de aplicação das restrições quantitativas no sector dos produtos da pesca (1), com a última redacção que lhe foi dada pelo Regulamento (CEE) nº 4064/86 (2), e, nomeadamente, o seu artigo 2º,

Considerando que o nº 3 do artigo 2º do Regulamento (CEE) nº 360/86 prevê a possibilidade da revisão, no decorrer do ano, do volume dos contingentes bem como a respectiva repartição trimestral tal como definidos pelo Regulamento (CEE) nº 4122/87 da Comissão (3);

Considerando que Portugal apresentou um pedido de aumento de 150 toneladas do nível do contingente de filetes de pescada do género Merluccius spp., congelados, fixado para a campanha de 1988; que é conveniente, portanto, adaptar o nível do contingente em causa bem como a respectiva repartição trimestral;

Considerando que, de acordo com o artigo 363º, nº 1, do Acto de Adesão de Espanha e de Portugal, Portugal pode manter, relativamente a países terceiros, restrições quantitativas para certos produtos; considerando que Portugal apresentou um pedido com vista à supressão das restrições quantitativas de potas, lulas e Illex spp. congelados; considerando, pertanto, que é conveniente, para estas espécies, suprimir o contingente respectivo bem como a repartição trimestral que figura no Regulamento (CEE) nº 4122/87;

Considerando que as medidas previstas no presente regulamento estão em conformidade com o parecer do Comité de Gestão dos Produtos da Pesca,

ADOPTOU O PRESENTE REGULAMENTO:

## Texto

### Artigo 1.º

1. No quadro constante da parte B do anexo do Regulamento (CEE) nº 4122/87, os números relativos aos filetes de pescada do género Merluccius spp., congelados, do código NC 0304 20 57 são substituídos pelo seguintes números:

1.2,5 // // // Contingente anual de importação // Fracção trimestral // // // 1.2.3.4.5 // // 1 // 2 // 3 // 4 // // // // // // 310 // 40 // 40 // 115 // 115 // // // // //

2. No quadro que figura na parte B do anexo ao Regulamento (CEE) nº 4122/87, a linha e os números relativos às lulas e potas (Ommastrephes spp., Loligo spp., Nototodarus spp., Sepioteuthis spp.) e Illex spp., congelados, dos códigos NC 0307 49 31, 0307 49 33, 0307 49 39, 0307 49 51, 0307 49 59 e 0307 99 11, são suprimidos.

### Artigo 2.º

O presente regulamento entra em vigor na data da sua publicação no Jornal Oficial das Comunidades Europeias.

O presente regulamento é obrigatório em todos os seus elementos e directamente aplicável em todos os Estados-membros.

Feito em Bruxelas, em 25 de Julho de 1988.
