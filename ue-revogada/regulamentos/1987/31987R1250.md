# Regulamento (CEE) n.º 1250/87 da Comissão de 5 de Maio de 1987 que altera pela segunda vez o Regulamento (CEE) n.º 3749/83 no que respeita aos montantes expressos em ECU

**Já não está em vigor** (fim de validade registado no Cellar: 1991-01-01). Serve para saber que regra se aplicava antes; para a regra actual, procurar o acto que o substituiu.

**Texto:** versão original publicada no Jornal Oficial (sem as alterações posteriores).

## Preâmbulo

A COMISSÃO DAS COMUNIDADES EUROPEIAS,

Tendo em conta o Tratado que institui a Comunidade Económica Europeia,

Tendo em conta o Regulamento (CEE) nº 3924/86 do Conselho, de 16 de Dezembro de 1986, que aplica preferências pautais generalizadas para o ano de 1987 a certos produtos industriais originários de países em vias de desenvolvimento (1), e, nomeadamente, o nº 4 do seu artigo 1º,

Tendo em conta o Regulamento (CEE) nº 3925/86 do Conselho, de 16 de Dezembro de 1986, que aplica preferências pautais generalizadas para o ano de 1987 aos produtos têxteis originários de países em vias de desenvolvimento (2), e, nomeadamente, o nº 3 do seu artigo 1º,

Tendo em conta o Regulamento (CEE) nº 3926/86 do Conselho, de 16 de Dezembro de 1986, que aplica preferências pautais generalizadas para o ano de 1987 a certos produtos agrícolas originários de países em vias de desenvolvimento (3), e, nomeadamente, o nº 2 do seu artigo 1º,

Considerando que a Decisão 86/638/CECA dos representantes dos governos dos Estados-membros da Comunidade Europeia do Carvão e do Aço reunidos no Conselho, de 16 de Dezembro de 1986, que aplica preferências pautais generalizadas para o ano de 1987 a determinados produtos siderúrgicos originários de países em vias de desenvolvimento (4), estabelece que a definição da origem dos produtos é fixada de acordo com o processo previsto nos termos do artigo 14º do Regulamento (CEE) nº 802/68 do Conselho, de 27 de Junho de 1968, relativo à definição comum da noção da origem das mercadorias (5), e que as regras a aplicar a este respeito devem ser idênticas às previstas para os outros produtos;

Considerando que, para acompanhar a evolução monetária, é necessário alterar pela segunda vez os montantes expressos em ECUs que figuram nos artigos 7º e 10º do Regulamento (CEE) nº 3749/83 da Comissão, de 23 de Dezembro de 1983, relativo à definição da noção de produtos originários para aplicação de preferências pautais concedidas pela Comunidade Europeia a certos produtos de países em vias de desenvolvimento (6), tal como foram alterados pelo Regulamento (CEE) nº 1061/85 (7);

Considerando que as medidas previstas no presente regulamento estão conformes com o parecer do Comité da Origem,

ADOPTOU O PRESENTE REGULAMENTO:

## Texto

### Artigo 1.º

O Regulamento (CEE) nº 3749/83 é alterado como segue:

1. No nº 2 do artigo 7º, o montante de « 2 355 ECUs » é substituído pelo montante de « 2 590 » ECUs.

2. A nota em pé-de-página referida no nº 2 do artigo 7º passa a ter a seguinte redacção:

« O contravalor em moedas nacionais do ECU é o seguinte:

1.2.3 // // 43,7750 // francos belgas/ /francos luxemburgueses // // 2,09022 // marcos alemães // // 2,36146 // florins neerlandeses // // 0,713486 // libra esterlina // 1 ECU = // 7,88477 // coroas dinamarquesas // // 6,84430 // francos franceses // // 1440,90 // liras italianas // // 0,762246 // libra irlandesa // // 139,754 // dracmas gregas // // 137,629 // pesetas espanholas // // 151,505 // escudos portugueses.

Os montantes em moeda nacional resultantes da conversão dos montantes em ECUs podem ser arredondados. »

3. No segundo parágrafo do nº 2 do artigo 10º os montantes de « 165 » e « 470 » ECUs são substituídos por « 180 » e « 515 » ECUs.

### Artigo 2.º

O presente regulamento entra em vigor na data da sua publicação no Jornal Oficial das Comunidades Europeias.

Produz efeitos a partir de 1 de Maio de 1987.

O presente regulamento é obrigatório em todos os seus elementos e directamente aplicável em todos os Estados-membros.

Feito em Bruxelas, em 5 de Maio de 1987.

Pela Comissão

COCKFIELD

Vice-Presidente
