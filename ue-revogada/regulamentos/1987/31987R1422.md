# Regulamento (CEE) n.º 1422/87 do Conselho de 21 de Maio de 1987 que altera o Regulamento (CEE) n.º 3626/82 relativo à aplicação na Comunidade da Convenção sobre o Comércio Internacional das Espécies Selvagens da Fauna e da Flora Ameaçadas de Extinção

**Já não está em vigor** (fim de validade registado no Cellar: 1987-10-22). Serve para saber que regra se aplicava antes; para a regra actual, procurar o acto que o substituiu.

**Texto:** versão original publicada no Jornal Oficial (sem as alterações posteriores).

## Preâmbulo

O CONSELHO DAS COMUNIDADES EUROPEIAS,

Tendo em conta o Tratado que institui a Comunidade Económica Europeia e, nomeadamente, o seu artigo 235º,

Tendo em conta a proposta da Comissão (1),

Tendo em conta o parecer do Parlamento Europeu (2),

Tendo em conta o parecer do Comité Económico e Social (3),

Considerando que a inclusão de todas as espécies de borboletas ornitópteras na Parte 1 do Anexo C do Regulamento (CEE) nº 3626/82 do Conselho, de 3 de Dezembro de 1982, relativo à aplicação na Comunidade da Convenção sobre o Comércio Internacional das Espécies Selvagens da Fauna e da Flora Ameaçadas de Extinção (4), com a última redacção que lhe foi dada pelo Regulamento (CEE) nº 2384/85 da Comissão (5), implica que sejam proibidas as importações na Comunidade de espécimes dessas espécies que se destinarem principalmente a fins comerciais;

Considerando que as operações de criação de borboletas ornitópteras são geralmente consideradas benéficas para a conservação daquelas espécies, contribuindo para o aumento das suas populações no estado selvagem;

Considerando que o êxito de tais operações de criação nos países em desenvolvimento depende largamente da possibilidade de escoamento comercial daqueles produtos; que aquele argumento não deverá, no entanto, ser utilizado para justificar uma transferência geral de espécies da Parte 1 para a Parte 2 do Anexo C do regulamento acima citado;

Considerando que é, por conseguinte, necessário autorizar as importações de espécimes de borboletas ornitópteras de criação; que a sua transferência da Parte 1 para a Parte 2 do referido anexo abre essa possibilidade, mantendo simultaneamente garantias suficientes para evitar as importações de espécimes de espécies e de populações de borboletas ornitópteras ameaçadas de extinção;

Considerando que a espécie de borboletas ornitópteras mais avançada, a Ornithoptera alexandrae, exige a mais rigorosa protecção possível e deveria portanto continuar na Parte 1 do mesmo anexo,

ADOPTOU O PRESENTE REGULAMENTO:

## Texto

### Artigo 1.º

O Regulamento (CEE) nº 3626/82 é alterado do seguinte modo:

1. No Anexo A, o texto da rubrica INSECTA-LEPIDOPTERA passa a ter a seguinte redacção:

1.2.3 // « LEPIDOPTERA // // // Borboletas e mariposas // Ornithoptera spp. = 356 // (C2) // Papilionidae // Ornithoptera alexandrae // (C1) // Machaons // Borboletas ornitópteras // // // Parnassius apollo // (C1) // // Borboletas apollo ou apollo de montanha // // // Trogonoptera spp. = 356 // (C2) // // Borboletas ornitópteras // // // Troides spp. = 356 // (C2) // // Borboletas ornitópteras. » //

2. Na Parte 1 do Anexo C, na rubrica INSECTA-LEPIDOPTERA:

- a menção « Ornithopera spp. = 356 » é substituída por « Ornithoptera alexandrae »,

e - as menções « Trogonoptera spp. = 356 » e « Troides spp. = 356 » são suprimidas.

3. Na Parte 2 do Anexo C, é inserida a seguinte rubrica, antes da rubrica ANTHOZOA:

« INSECTA

LEPIDOPTERA

Papilionidae

1.2 // Ornithoptera spp. // = 356 (com excepção da Ornithoptera alexandrae, incluída na Parte 1) // Trogonoptera spp. // = 356

Troides spp. = 356 ».

### Artigo 2.º

O presente regulamento entra em vigor a data da sua publicação no Jornal Oficial das Comunidades Europeias.

O presente regulamento é obrigatório em todos os seus elementos e directamente aplicável em todos os Estados-membros.

Feito em Bruxelas, em 21 de Maio de 1987.

Pelo Conselho

O Presidente

M. SMET
