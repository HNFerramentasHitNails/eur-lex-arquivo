# Regulamento (CEE) n.º 2869/87 da Comissão de 25 de Setembro de 1987 que altera o Regulamento n.º 225/67/CEE, relativo às regras de determinação do preço para as sementes oleaginosas no mercado mundial

**Já não está em vigor** (fim de validade registado no Cellar: 1993-12-17). Serve para saber que regra se aplicava antes; para a regra actual, procurar o acto que o substituiu.

**Texto:** versão original publicada no Jornal Oficial (sem as alterações posteriores).

## Preâmbulo

A COMISSÃO DAS COMUNIDADES EUROPEIAS,

Tendo em conta o Tratado que institui a Comunidade Económica Europeia,

Tendo em conta o Regulamento nº 136/66/CEE do Conselho, de 22 de Setembro de 1966, que estabelece uma organização comum de mercado no sector das matérias gordas (1), com a última redacção que lhe foi dada pelo Regulamento (CEE) nº 1915/87 (2),

Tendo em conta o Regulamento nº 115/67/CEE do Conselho, de 6 de Junho de 1967, que fixa os critérios para a determinação do preço do mercado mundial das sementes oleaginosas bem como o local de passagem na fronteira (3), com a última redacção que lhe foi dada pelo Regulamento (CEE) nº 1983/82 (4), e, nomeadamente, o seu artigo 7º,

Considerando que o artigo 3º do Regulamento nº 225/ /67/CEE da Comissão (5), com a última redacção que lhe foi dada pelo Regulamento (CEE) nº 2284/86 (6), prevê que, no caso de as ofertas e as cotações respeitarem a uma qualidade que não seja a qualidade-tipo para a qual foi fixado o preço indicativo, o seu montante é ajustado em conformidade com os coeficientes de equivalência incluídos no anexo; quea evolução das cotações no mercado mundial conduz a uma nova fixação dos coeficientes de equivalência;

Considerando que, pelo Regulamento (CEE) nº 1917/87 (7), o Conselho fixou, para a campanha de comercialização de 1987/1988 o preço indicativo para as sementes de girassol com um teor de humidade de 9 %; que convém ajustar, para a mesma campanha, os coeficientes de equivalência em causa que constam do anexo do Regulamento nº 225/67/CEE e que foram fixados para as sementes de girassol com um teor em óleo de 10 %;

Considerando que as medidas previstas no presente regulamento estão em conformidade com o parecer do Comité de Gestão das Matérias Gordas,

ADOPTOU O PRESENTE REGULAMENTO:

## Texto

### Artigo 1.º

O quadro do Anexo do Regulamento nº 225/67/CEE é substituído pelo quadro seguinte:

« (Em ECUs/100 kg)

1.2,3 // // // // Coeficiente de equivalência // 1.2.3 // // Montante a deduzir do preço // Montante a acrescentar ao preço // // // // A. Sementes de colza e de nabita em proveniência: // // // - do Canadá // 0,429 // - // - dos outros países terceiros // 0,246 // - // B. Sementes de girassol em proveniência: // // // - dos Estados Unidos da América ou Canadá // - // 1,741 (1) resp. 0,960 // - dos outros países terceiros // - // 1,675 (1) resp. 1,195 // // //

(1) A aplicar a partir de 1 de Abril de 1987 aos preços verificados para a determinação do preço do mercado mundial antes da data da entrada em vigor do presente regulamento para a campanha de comercialização de 1987/1988. »

### Artigo 2.º

O presente regulamento entra em vigor no terceiro dia seguinte ao da sua publicação no Jornal Oficial das Comunidades Europeias.

O presente regulamento é obrigatório em todos os seus elementos e directamente aplicável em todos os Estados-membros.

Feito em Bruxelas, em 25 de Setembro de 1987.
