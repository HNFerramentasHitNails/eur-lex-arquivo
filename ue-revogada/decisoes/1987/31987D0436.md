# 87/436/CEE: Decisão da Comissão de 29 de Julho de 1987 relativa aos montantes da contribuição do Fundo Social Europeu para as despesas de apoio à contratação, à instalação e à obtenção de experiência de trabalho

**Já não está em vigor** (fim de validade registado no Cellar: 1988-12-31). Serve para saber que regra se aplicava antes; para a regra actual, procurar o acto que o substituiu.

**Texto:** versão original publicada no Jornal Oficial (sem as alterações posteriores).

## Preâmbulo

A COMISSÃO DAS COMUNIDADES EUROPEIAS,

Tendo em conta o Tratado que institui a Comunidade Económica Europeia,

Tendo em conta a Decisão 83/516/CEE do Conselho, de 17 de Outubro de 1983, relativa às atribuições do Fundo Social Europeu (1), alterada pela Decisão 85/568/CEE (2),

Tendo em conta o Regulamento (CEE) nº 2950/83 do Conselho, de 17 de Outubro de 1983, que aplica a Decisão 83/516/CEE do Conselho, relativa as atribuições do Fundo Social Europeu (3), com a última redacção que lhe foi dada pelo Regulamento (CEE) nº 3824/85 (4), e, nomeadamente, o seu artigo 2º,

Considerando que compete à Comissão determinar os montantes da contribuição para despesas de apoio à contratação, à instalação e à obtenção de experiência de trabalho aplicáveis para o exercício orçamental de 1988, tal como designadas na alínea c) do artigo 1º do Regulamento (CEE) nº 2950/83,

ADOPTOU A PRESENTE DECISÃO:

## Texto

### Artigo 1.º

Os montantes da contribuição do Fundo Social Europeu para as despesas de apoio à contratação, à instalação e à obtenção de experiência de trabalho para o exercício de 1988, tal como designadas na alínea c) do artigo 1º do Regulamento (CEE) nº 2950/83, são fixados, por pessoa e por semana, como segue:

1.2.3 // - Bélgica: // 1 650 // FB, // - Dinamarca: // 453 // Dkr, // - Alemanha: // 101 // DM, // - Grécia: // 2 768 // DR, // - Espanha: // 5 392 // Pta, // - França: // 239 // FF, // - Irlanda: // 28 // £Irl, // - Itália: // 49 900 // Lit, // - Luxemburgo: // 2 058 // Flux, // - Holanda: // 102 // Fl, // - Portugal: // 2 387 // Esc, // - Reino Unido: // 26 // £.

### Artigo 2.º

Os montantes previstos no artigo 1º dizem respeito às acções de contratação, de instalação e de experiência de trabalho relativas a empregos a tempo inteiro. No caso de empregos a tempo parcial, os montantes são calculados proporcionalmente ao número de horas prestadas, na base de quarenta horas por semana.

### Artigo 3.º

Os Estados membros são destinatários da presente decisão.

Feito em Bruxelas, em 29 de Julho de 1987.
