# 86/528/CEE: Decisão do Conselho de 3 de Novembro de 1986 que altera a Decisão 78/476/CEE relativa à equivalência dos controlos das selecções de conservação efectuados nos países terceiros

**Já não está em vigor** (fim de validade registado no Cellar: 1988-06-30). Serve para saber que regra se aplicava antes; para a regra actual, procurar o acto que o substituiu.

**Texto:** versão original publicada no Jornal Oficial (sem as alterações posteriores).

## Preâmbulo

O CONSELHO DAS COMUNIDADES EUROPEIAS,

Tendo em conta o Tratado que institui a Comunidade Económica Europeia,

Tendo em conta a Directiva 70/457/CEE do Conselho, de 29 de Setembro de 1970, relativa ao catálogo comum das variedades das espécies de plantas agrícolas (1), com a última redacção que lhe foi dada pela Directiva 86/155/CEE (2), e, nomeadamente, o nº 1, alínea b), do seu artigo 21º,

Tendo em conta a proposta da Comissão,

Considerando que, pela sua Decisão 78/476/CEE (3), com a última redacção que lhe foi dada pela Decisão 85/587/CEE (4), o Conselho verificou que os controlos oficiais das selecções de conservação efectuados em determinados países terceiros oferecem as mesmas garantias que os controlos efectuados pelos Estados-membros;

Considerando que se verificou, entretanto, que, para determinadas espécies, as selecções de conservação podem ser igualmente submetidas a controlos oficiais na Argentina;

Considerando que a análise das condições dos controlos oficiais das selecções de conservação efectuadas na Argentina permitiu verificar que esses controlos oferecem as mesmas garantias que os efectuados pelos Estados-membros;

Considerando que é conveniente, portanto, que a Argentina beneficie da equivalência em relação a determinadas espécies,

ADOPTOU A PRESENTE DECISÃO:

## Texto

### Artigo 1.º

No anexo da Decisão 78/476/CEE, é inserida a rubrica seguinte após a rubrica 6A:

1.2.3.4 // // // // // 1 // 2 // 3 // 4 // // // // // « 6B // Argentina (RA) // Serviço Nacional de Semillas, Buenos Aires // Zea mays Helianthus annuus. » // // // //

### Artigo 2.º

Os Estados-membros são destinatários da presente decisão.

Feito em Bruxelas, em 3 de Novembro de 1986.

Pelo Conselho

O Presidente
