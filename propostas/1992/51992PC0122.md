              EXPOSIÇÃO DE MOTIVOS


O Regulamento (CEE) N a 2658/87 do Conselho, de 23 de
Julho de 1987 instituiu, com efeitos a partir de
Janeiro de 1988, uma nomenclatura de mercadorias
denominada   Nomenclatura    Combinada    (NC)   para
satisfazer as necessidades quer da Pauta Aduaneira
Comum quer das estatísticas do comércio externo da
Comunidade.

A Comissão    instituiu uma pauta integrada das
Comunidades Europeias, denominada "Taric", baseada
na Nomenclatura Combinada. A Taric é não só
utilizada como base para as pautas de serviço
nacionais como também serve como base para a recolha
de dados estatísticos relativos às importações de
países terceiros. Segundo os termos do Regulamento
(CEE) N 8 2658/87 está previsto que as subdivisões
nacionais sejam formadas pelo nono dígito entre os
códigos   NC   (sétimo   e oitavo dígitos)    e   as
subdivisões   Taric    (décimo  e  décimo   primeiro
dígitos).

Isto significa que a progressão natural dos códigos
do   Sistema    Harmonizado    para    os   códigos   da
Nomenclatura    Combinada   e   da    Taric,   que   são
requeridos para fins comunitários, é interrompida
para efeitos de estatística nacional. Este facto
criou dificuldades, ao nível comunitário, no que diz
respeito    à     automatização     dos    procedimentos
aduaneiros    e   à   sua   utilização    no   Documento
Administrativo Único (DAU).
                                               3
De forma a evitar estas dificuldades e a assegurar
uma estrutura hierarquia dos códigos mais coerente,
considera-se   que    deve   ser previsto  que   as
subdivisões nacionais surjam após as subdivisões
Taric. Estas modificações requerem uma alteração do
Regulamento (CEE) N B 2658/87.

O projecto de Regulamento servirá como medida de
acompanhamento ao Mercado Interno, mas propõe-se que
a sua aplicação seja diferida até 1 de Janeiro de
1994 afim de permitir que os Estados-tóembros tenham
o tempo necessário para a implementação das novas
provisões
