# Acórdão do Tribunal de Justiça (Sexta Secção) de 7 de março de 2024. — Endemol Shine Finland Oy. — Reenvio prejudicial — Proteção de dados pessoais — Regulamento (UE) 2016/679 — Artigos 2.°, 4.°, 6.°, 10.° e 86.° — Dados detidos por um tribunal relativos às condenações penais de uma pessoa singular — Comunicação verbal desses dados a uma sociedade comercial devido a um concurso organizado por esta — Conceito de “tratamento de dados pessoais” — Legislação nacional que regula o acesso aos referidos dados — Conciliação entre o direito do público de acesso a documentos oficiais e a proteção de dados pessoais. — Processo C-740/22.

## Texto

Processo C‑740/22

Endemol Shine Finland Oy

(pedido de decisão prejudicial apresentado pelo Itä‑Suomen hovioikeus)

Acórdão do Tribunal de Justiça (Sexta Secção) de 7 de março de 2024

«Reenvio prejudicial — Proteção de dados pessoais — Regulamento (UE) 2016/679 — Artigos 2.°, 4.°, 6.°, 10.° e 86.° — Dados detidos por um tribunal relativos às condenações penais de uma pessoa singular — Comunicação verbal desses dados a uma sociedade comercial devido a um concurso organizado por esta — Conceito de “tratamento de dados pessoais” — Legislação nacional que regula o acesso aos referidos dados — Conciliação entre o direito do público de acesso a documentos oficiais e a proteção de dados pessoais»

- 1. Proteção das pessoas singulares no que diz respeito ao tratamento de dados pessoais — Regulamento 2016/679 — Âmbito de aplicação — Conceito de tratamento de dados pessoais — Comunicação oral dos dados relativos às condenações penais de uma pessoa singular — Inclusão — Requisito — Dados contidos em ficheiros ou a eles destinados

  (Regulamento 2016/679 do Parlamento Europeu e do Conselho, artigo 4.o, n.os 2 e 6)

  (cf. n.os 28‑32, 35‑39, disp. 1)

- 2. Atos das instituições — Regulamentos — Aplicabilidade direta — Regulamento 2016/679 — Comunicação verbal dos dados relativos às condenações penais de uma pessoa singular — Regulamentação nacional que não exige o respeito das disposições nacionais relativas à proteção de dados pessoais para a comunicação oral desses dados — Não incidência

  (Artigo 288.o, segundo parágrafo, TFUE; Regulamento 2016/679 do Parlamento Europeu e do Conselho)

  (cf. n.os 42‑44)

- 3. Proteção das pessoas singulares no que diz respeito ao tratamento de dados pessoais — Regulamento 2016/679 — Requisitos de licitude de um tratamento de dados pessoais — Tratamento necessário ao exercício de funções de interesse público ou ao exercício da autoridade pública — Tratamento de dados pessoais relativos a condenações penais e infrações — Comunicação oral dos dados relativos às condenações penais de uma pessoa singular — Direito de acesso do público aos documentos oficiais — Obrigação de justificar um interesse específico — Inexistência — Inadmissibilidade — Qualidade da pessoa que pede o acesso aos dados — Não incidência

  [Carta dos Direitos Fundamentais da União Europeia, artigos 7.°, 8.° e 52.°, n.o 1; Regulamento 2016/679 do Parlamento Europeu e do Conselho, considerandos 4, 39, 154 e artigos 5.°, n.o 1, alínea a), 6.°, n.o 1, alínea e), 10.°, 85.° e 86.°]

  (cf. n.os 46‑49, 53‑58, disp. 2)
