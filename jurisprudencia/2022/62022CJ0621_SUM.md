# Acórdão do Tribunal de Justiça (Nona Secção) de 4 de outubro de 2024. — Koninklijke Nederlandse Lawn Tennisbond contra Autoriteit Persoonsgegevens. — Reenvio prejudicial — Proteção das pessoas singulares no que diz respeito ao tratamento de dados pessoais — Regulamento (UE) 2016/679 — Artigo 5.°, n.º 1, alínea a) — Licitude do tratamento — Artigo 6.°, n.º 1, primeiro parágrafo, alínea f) — Necessidade do tratamento para efeitos dos interesses legítimos prosseguidos pelo responsável pelo tratamento ou por terceiros — Conceito de “interesses legítimos” — Interesse comercial — Federação desportiva — Comunicação a título oneroso dos dados pessoais dos membros de uma federação desportiva a patrocinadores sem o consentimento desses membros. — Processo C-621/22.

## Texto

Processo C‑621/22

Koninklijke Nederlandse Lawn Tennisbond

contra Autoriteit Persoonsgegevens

(pedido de decisão prejudicial apresentado pelo rechtbank Amsterdam)

Acórdão do Tribunal de Justiça (Nona Secção) de 4 de outubro de 2024

«Reenvio prejudicial — Proteção das pessoas singulares no que diz respeito ao tratamento de dados pessoais — Regulamento (UE) 2016/679 — Artigo 5.o, n.o 1, alínea a) — Licitude do tratamento — Artigo 6.o, n.o 1, primeiro parágrafo, alínea f) — Necessidade do tratamento para efeitos dos interesses legítimos prosseguidos pelo responsável pelo tratamento ou por terceiros — Conceito de “interesses legítimos” — Interesse comercial — Federação desportiva — Comunicação a título oneroso dos dados pessoais dos membros de uma federação desportiva a patrocinadores sem o consentimento desses membros»

Proteção das pessoas singulares no que diz respeito ao tratamento de dados pessoais — Regulamento 2016/679 — Requisitos de licitude de um tratamento de dados pessoais — Tratamento necessário para efeitos dos interesses legítimos prosseguidos pelo responsável pelo tratamento ou por terceiros, exceto se prevalecerem os interesses ou direitos e liberdades fundamentais do titular dos dados, que exijam a proteção dos dados — Conceito — Comunicação a título oneroso de dados dos membros de uma federação desportiva para satisfazer um interesse comercial do responsável pelo tratamento — Inclusão — Requisito

(Carta dos Direitos Fundamentais da União Europeia, artigo 8.o; Regulamento 2016/679 do Parlamento Europeu e do Conselho, considerando 47 e artigos 5.°, 6.°, n.o 1, primeiro parágrafo, alínea f), e 13.°, n.o 1, alíneas c) e d)]

(cf. n.os 25, 29‑31, 35‑42, 45‑51, 54, 55 e disp.)
