# Acórdão do Tribunal de Justiça (Quinta Secção) de 3 de junho de 2021. — «CV-Online Latvia» SIA contre «Melons» SIA. — Reenvio prejudicial — Proteção jurídica das bases de dados — Diretiva 96/9/CE — Artigo 7.º — Direito “sui generis” dos fabricantes de bases de dados — Proibição de terceiros “extrair” ou “reutilizar”, sem autorização do fabricante, a totalidade ou uma parte substancial do conteúdo da base de dados — Base de dados livremente acessível na Internet — Metamotor de busca especializado em anúncios de emprego — Extração e/ou reutilização do conteúdo de uma base de dados — Prejuízo causado ao investimento substancial na obtenção, verificação ou apresentação de uma base de dados. — Processo C-762/19.

## Texto

Processo C‑762/19

«CV‑Online Latvia» SIA

contra «Melons» SIA

(pedido de decisão prejudicial apresentado pelo Rīgas apgabaltiesas Civillietu tiesas kolēģija)

Acórdão do Tribunal de Justiça (Quinta Secção) de 3 de junho de 2021

«Reenvio prejudicial — Proteção jurídica das bases de dados — Diretiva 96/9/CE — Artigo 7.o — Direito “sui generis” dos fabricantes de bases de dados — Proibição de terceiros “extrair” ou “reutilizar”, sem autorização do fabricante, a totalidade ou uma parte substancial do conteúdo da base de dados — Base de dados livremente acessível na Internet — Metamotor de busca especializado em anúncios de emprego — Extração e/ou reutilização do conteúdo de uma base de dados — Prejuízo causado ao investimento substancial na obtenção, verificação ou apresentação de uma base de dados»

- 1. Aproximação das legislações — Proteção jurídica das bases de dados — Diretiva 96/9 — Conceito de investimento ligado à obtenção, à verificação ou à apresentação do conteúdo de uma base de dados

  (Diretiva 96/9 do Parlamento Europeu e do Conselho, artigo 7.o, n.o 1)

  (cf. n.os 24‑28, 43)

- 2. Aproximação das legislações — Proteção jurídica das bases de dados — Diretiva 96/9 — Direito de o fabricante de uma base de dados proibir a extração e/ou a reutilização da totalidade ou de uma parte substancial do conteúdo desta (direito sui generis) — Conceito de reutilização — Colocação online na Internet, pelo seu explorador, de um metamotor de busca dedicado — Inclusão — Critérios de apreciação

  [Diretiva 96/9 do Parlamento Europeu e do Conselho, artigo 7.o, n.os 1 e 2, alínea b)]

  (cf. n.os 29‑32, 39, 40, 47)
